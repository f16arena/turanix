# Turanix

Corporate landing page for Turanix LLP: websites, mobile apps, business automation, Telegram integrations and AI consultants.

## Stack

- Next.js App Router
- TypeScript
- React
- Tailwind CSS
- Motion
- Lenis

## Development

```bash
npm install
npm run dev
```

Local URL: `http://localhost:3000`

## Production

```bash
npm run build
npm run start
```
